🛡️ Smart Security Agent
Admin control center for Smart. Monitor threats by default; automatic blocking is optional and can be disabled at any time.

Shared-IP protection is enabled: Smart will not automatically block an IP already associated with multiple student accounts; those cases are flagged for Admin review instead.
