SMARTTEP V58 — ADMIN BACKUP GUIDE

1. Sign in to the SMARTTEP Admin Portal.
2. Complete Admin 2FA if it is enabled.
3. Open “Database Backup & Admin Audit Trail”.
4. Select “Download database backup”. Confirm the warning.
5. Wait for the JSON file to finish downloading. Do not close the page while it is downloading.
6. Move the file to a private, encrypted storage location. Do not upload it to GitHub or share it publicly.
7. Keep a separate secure copy of the exact NIN_ENCRYPTION_KEY used by this deployment. Never place the key inside the backup file.
8. Review recent administrator activity in the audit table. The table intentionally does not include form contents or NIN values.

This feature exports data; it does not automatically restore it. Do not attempt a restore by importing the entire JSON file as one MongoDB collection. A tested collection-by-collection restore procedure is a separate upgrade.
