SMARTTEP ACADEMY V58 — SECURITY AUDIT & DATABASE BACKUP EXPORT

Built on V57. Existing V57 NIN protection, course counts, community, courses, payments, scholarships, exams, advertising, instructor and moderator features are retained.

Added:
- Admin-only recent audit log for write requests that pass the Admin middleware. Logs method, path, response status, admin email, IP and time. Request bodies are deliberately not logged, preventing NINs, passwords and payment proof data from being copied into audit records.
- Admin-only streamed JSON database export to reduce memory pressure.
- Backup excludes login-session collections so restored users must sign in again. Encrypted NIN fields remain encrypted; the backup does not contain NIN_ENCRYPTION_KEY.
- Backup export requires normal Admin authentication and existing Admin 2FA when enabled.

No new environment variables, npm packages, accounts or paid subscriptions are required.

Important limitations:
- This is a manual backup export, not automatic scheduled backup and not a one-click restore tool. Keep a secure copy and arrange a tested restore procedure before relying on it as disaster recovery.
- The downloaded JSON contains confidential records and password hashes. Store it encrypted and restrict access. Never upload it to a public GitHub repository or share it in chats.
- Keep NIN_ENCRYPTION_KEY backed up separately and securely. Without the same key, encrypted NINs cannot be decrypted.
- Large databases may take time to export; download while the Render service is awake and avoid interrupting the request.

Validation: JavaScript syntax and ZIP integrity checks are performed locally. Live Render, MongoDB, Cloudinary, browser and restore testing are not performed in this environment.
