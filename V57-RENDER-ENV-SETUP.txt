SMARTTEP ACADEMY V57 — ADD THE NIN ENCRYPTION KEY IN RENDER

You do not need another account or a paid subscription.

STEP 1 — Generate your private key on your Windows laptop
1. Open Command Prompt or PowerShell.
2. Type this command and press Enter:
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
3. Node.js will display a 64-character value made of letters and numbers.
4. Copy it and keep it in a trusted password manager or another secure offline location.

STEP 2 — Add it to the existing Render service
1. Sign in to Render.
2. Open the existing SMARTTEP ACADEMY Web Service.
3. Open Environment in the service menu.
4. Choose Add Environment Variable.
5. Key / Name: NIN_ENCRYPTION_KEY
6. Value: paste the 64-character value you generated.
7. Save the changes. Render will redeploy/restart the service.

STEP 3 — Keep the key safe
- Never paste the real key into GitHub, source code, screenshots, messages or public documents.
- Do not generate a new key each time you deploy.
- Back it up securely. If it is lost or changed, old NIN values cannot be decrypted and duplicate checks will no longer match old fingerprints.

STEP 4 — Deploy V57
1. Download and extract the V57 ZIP.
2. Replace the files in the GitHub repository with the extracted V57 project files. Do not delete the repository or change the MongoDB database.
3. Commit/push the updated files to the same GitHub repository connected to Render.
4. Wait for the existing Render service to finish deploying.
5. Check the Admin Portal's Security Health area for the NIN encryption key check.

The 30-day existing-user NIN deadline starts only after the key is configured and V57 first completes its database startup migration. New registrations require NIN immediately.

No new npm package, database account, Cloudinary account, payment account or paid subscription is required. Community media uses your existing Cloudinary account and remains subject to its free-plan storage and bandwidth limits.
